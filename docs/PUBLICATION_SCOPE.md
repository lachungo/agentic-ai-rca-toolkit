# Publication Scope

## Published

- Working SQL source for the certified RCA V1 development chain
- Operational front door, collection, target-scoping, HTML writer, and renderer
- Controlled positive-control workloads
- Certification and freeze evidence
- Sanitized HTML report examples
- Architecture, deployment, runbook, and interview documentation

## Excluded

- Raw `.xel` telemetry and customer evidence
- Credentials, secrets, certificates, proxy configuration, and service-account details
- Machine-specific output files and personal server/login identities
- Customer database schemas, queries, plans, parameters, and incident narratives
- Commercial engagement templates and any future private extensions

## Legal and practical boundary

The repository is source-available for portfolio review under an All Rights Reserved notice. It is not open source. No permission is granted to deploy, copy, redistribute, resell, or create derivative implementations.

Source publication cannot technically prevent unauthorized copying. The defensible protection is a combination of copyright, retained authorship history, careful exclusion of customer data and secrets, and keeping future commercial enhancements private.

## Positioning

Describe the repository as a **functional consulting portfolio edition**: it demonstrates implementation depth and can be retained by the author for future engagements, but it is not offered as a supported public product.
