# Security and Responsible Use

Do not open a public issue containing SQL text, execution plans, runtime parameters, `.xel` files, login names, server names, connection strings, or customer incident data.

The acceptance workloads intentionally create blocking and resource pressure. They are restricted to isolated non-production environments.

No credentials or certificates belong in this repository. Environment-specific paths and identities must be supplied and reviewed during deployment.

For a private security report, contact the repository owner through the contact method listed on the author's portfolio.
